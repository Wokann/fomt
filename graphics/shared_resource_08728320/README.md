# Shared resource `08728320`

`full/group_*.png` are the editable palette-indexed OAM-composited views of a
fixed `0x105C`-byte `IndexedResourceArchive`. Native selectors, descriptors,
OAM, tile placement, and BGR555 palette data remain the layout source; no JSON
sidecar is used.

The complete archive is byte-identical at JP `0x4AE488`, US `0x728320`, EU
`0x72837C`, and DE `0x4AF4EC`. `preview/` is reference-only; compilation reads
`full/` only.
