# Shared resource `08726CCC`

`full/group_000.png` is the editable palette-indexed OAM-composited view of a
fixed `0x69C`-byte `IndexedResourceArchive`. Native selector, descriptor, OAM,
tile-placement, and BGR555 palette data remain the layout source; no JSON
sidecar is used. The archive is byte-identical at JP `0x4ACE34`, US `0x726CCC`,
EU `0x726D28`, and DE `0x4ADE98`.

`preview/` is reference-only; compilation reads `full/` only.
