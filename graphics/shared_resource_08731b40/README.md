# Shared resource `08731B40`

`full/group_*.png` are the editable palette-indexed OAM-composited views of a
fixed `0x6604`-byte `IndexedResourceArchive`. Native selectors, descriptors,
OAM, tile placement, and BGR555 palette data remain the layout source; no JSON
sidecar is used.

The complete archive is byte-identical at JP `0x4B7CA8`, US `0x731B40`, EU
`0x731B9C`, and DE `0x4B8EAC`. `preview/` is reference-only; compilation reads
`full/` only.
